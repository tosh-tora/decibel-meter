# Decibel Meter

コンサートホールのスクリーン向け、リアルタイム音量表示アプリケーション。

マイク入力から dB SPL を計算して大型表示し、120秒間の音量推移をグラフで可視化します。

## 動作環境

- **OS**: Windows 10 / 11 専用（WASAPI を使用するため）
- **Python**: 3.10 以上
- **マイク**: 入力デバイスが必要。**マイクの拡張機能（ノイズキャンセル・エコーキャンセルなど）は必ず無効にすること**

> Windows のノイズキャンセル等の音声処理が有効だと音量特性が変わり、キャリブレーション値がずれたり計測が不安定になります。

### マイク拡張機能の無効化手順

1. タスクバーのスピーカーアイコンを右クリック →「サウンドの設定」を開く
2. 画面右側「入力」の「デバイスのプロパティ」をクリック（または コントロールパネル → サウンド → 録音タブ）
3. 使用するマイクを右クリック →「プロパティ」
4. 「拡張機能」タブを開く
5. **「すべての拡張機能を無効にする」にチェック**を入れて「適用」→「OK」

> 「拡張機能」タブが表示されない場合は、そのマイクドライバーが拡張機能を持っていないため設定不要です。

## インストール

```bash
pip install -r requirements.txt
```

## 起動

```bash
python decibel_meter.py
```

## 起動フロー

```
起動
 ├─ calibration.json あり → [startup] 前回値確認
 │    ├─ Enter  → [noise_setup] 暗騒音設定
 │    ├─ S      → [main] スキップ
 │    └─ R      → [calib_step1]
 └─ なし → [calib_step1] キャリブレーション STEP 1
               ↓ Enter
           [calib_step2] キャリブレーション STEP 2
               ↓ Enter（または S で1点のみ）
           [calib_confirm] 確認
               ↓ Enter / S
           [noise_setup] 暗騒音設定
               ↓ Enter
           [noise_measure] 計測中（自動完了）
               ↓
           [main] 計測画面
```

## キャリブレーション

dB SPL の絶対値表示には1点または2点キャリブレーションが必要です。

1. スマホの騒音計アプリ（例: [NIOSH SLM](https://www.cdc.gov/niosh/topics/noise/app.html)）を用意する
2. **STEP 1**: 静かな音（pp の弱音など）を出し、騒音計の値を入力して Enter
3. **STEP 2**: 大きな音（ff の強奏など）を出し、騒音計の値を入力して Enter（`S` で1点のみ確定）
4. キャリブレーション結果は `calibration.json` に保存され、次回起動時に自動読み込み

> スキップした場合は相対値で表示されます（絶対値は不正確）。

## 暗騒音ゲート

キャリブレーション後に暗騒音（ホール静寂時の床雑音）を測定し、それ以下の音量では表示を凍結するノイズゲートを設定できます。

| 設定項目 | 既定値 | 範囲 | 説明 |
|----------|--------|------|------|
| 計測時間 | 10秒 | 3〜60秒 | 暗騒音サンプリング時間 |
| パーセンタイル | 10% | 5〜50% | 下位N%をフロア値とする |
| マージン | 5 dB | 0〜20 dB | フロアに加算するゲート閾値 |

`noise_setup` 画面で ↑↓ キーで行選択、←→ キーで値を調整します。`S` でスキップ（ゲートなし）。

## 操作方法

### キャリブレーション・設定画面

| キー | 動作 |
|------|------|
| `Enter` | 確定 / 次へ進む |
| `S` | スキップ |
| `R` | キャリブレーションからやり直し |
| `↑` / `↓` | 項目選択（noise_setup） |
| `←` / `→` | 値変更（noise_setup） |
| `Q` / `Esc` | 終了 |

### 計測画面（main）

| キー | 動作 |
|------|------|
| `Space` | 計測開始 / 停止 |
| `N` | 暗騒音を再測定 |
| `F` | フルスクリーン切替（プロジェクター投影時） |
| `Tab` | オペレーター情報オーバーレイ表示/非表示 |
| `R` | 再キャリブレーション |
| `Q` / `Esc` | 終了 |

## 表示について

- **中央の大きな数字**: 暖白色（255, 250, 200）で固定。暗い客席からも見やすい色
- **グラフ折れ線・統計値の色**: 音量レベルに応じて変化
  - シアングリーン: ～70 dB（静かな会話レベル）
  - 明黄: 70～90 dB（交通騒音レベル）
  - 明橙: 90～110 dB（工事現場レベル）
  - 明赤: 110 dB～（ライブ・航空機エンジンレベル）
- **セッション統計**: 計測開始後、画面左に最大値（上）・最小値（下）を表示
  - `R` キーで再キャリブレーション時にリセット、一時停止中は保持
- **数字のリフレッシュ**: `DISP_HZ`（既定 3 Hz）ごとに更新。インターバル内の**最大値**を表示
- **グラフ**: 直近120秒間の音量推移（12.5 Hz サンプリング）
- **ノイズゲート発動時**: 数字が暗くなり表示が凍結

## 技術仕様

| 項目 | 値 |
|------|----|
| サンプリングレート | 44,100 Hz |
| ブロックサイズ | 1,024 サンプル（約23ms） |
| 平滑化 | 指数移動平均（α=0.3） |
| グラフ更新レート | 12.5 Hz |
| 数字表示更新レート | 3 Hz（インターバル内の最大値を表示、`DISP_HZ` で変更可） |
| グラフ履歴 | 120秒 |
| キャリブレーション方式 | 1点または2点線形回帰（dB_SPL = a × dB_raw + b） |
| オーディオ入力 | WASAPI 排他モード優先、失敗時は共有モードへ自動フォールバック |
| ウィンドウ | シングルウィンドウ、リサイズ可能・フォントサイズ自動スケール |
